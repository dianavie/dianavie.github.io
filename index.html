UI/UX

Así trabajo una interfaz, desde la idea hasta que alguien la usa.

  1. Entender

    Defino quién la usa y qué necesita lograr en la pantalla.

  2. Bocetar

    Dibujo wireframes para ordenar el contenido antes de poner color.

  3. Prototipar

    Armo un prototipo navegable para ver el flujo completo.

  4. Probar

    Hago pruebas de usabilidad con personas reales y ajusto lo que confunde.

HTML y CSS

Esta página está hecha solo con HTML y CSS, sin plantillas. Abajo hay un extracto de su código y su paleta.

estilos.css
/* Colores como variables */
:root {
  --hot: #c2185b;
  --candy: #ff8fbf;
  --blush: #ffd6e8;
  --ink: #3a0f2e;
}

/* Etiqueta tipo sticker */
.sticker {
  background: var(--candy);
  border: 2px solid var(--ink);
  border-radius: 999px;
  transform: rotate(-4deg);
}
